# Bidepzai Shop

Website mẫu bán hàng dùng React + Vite.

## Chạy trên máy
1. Cài Node.js.
2. Chạy `npm install`
3. Chạy `npm run dev`

## Triển khai Cloudflare
- Build command: `npm run build`
- Build output directory: `dist`

## Lưu ý
Đây là giao diện mẫu. Giỏ hàng hiện chỉ hoạt động trên trình duyệt, chưa có thanh toán, lưu đơn hàng, quản trị sản phẩm hoặc kết nối vận chuyển. Hãy thay sản phẩm, thông tin liên hệ và thiết lập quy trình nhận đơn trước khi kinh doanh thật.
